# Лабораторная работа: Обработка строк и коллекций

## Обзор проекта
Данное консольное приложение предназначено для автоматизированного редактирования текстовых файлов в заданной директории. Программа выполняет пакетную обработку данных, исправляя типичные орфографические ошибки и приводя номера мобильных телефонов к единому международному стандарту.

## Функциональные возможности
- **Сканирование директории**: Автоматический поиск всех файлов с расширением .txt по указанному пользователем пути.
- **Коррекция текста**: Замена ошибочных написаний слов на правильные на основе встроенного словаря (Dictionary).
- **Нормализация телефонных номеров**: Обнаружение номеров в формате (0XX) XXX-XX-XX и их преобразование в формат +380 XX XXX XX XX.

## Техническая реализация

### Использование коллекций
Для хранения пар «ошибочное слово — исправление» используется коллекция `Dictionary<string, string>`. Это обеспечивает эффективный поиск и подстановку значений. В логике реализована проверка границ слов (\b), что исключает некорректную замену частей других слов.

### Работа с регулярными выражениями
Для обработки текстового контента используется пространство имен `System.Text.RegularExpressions`.

1. **Исправление ошибок**:
   - Шаблон: `\b{Ключ_Словаря}\b`
   - Опции: `RegexOptions.IgnoreCase` (игнорирование регистра).
   - Метод `Regex.Escape` используется для безопасного экранирования спецсимволов.

2. **Форматирование номеров**:
   - Исходный паттерн: `\(0(\d{2})\)\s?(\d{3})-(\d{2})-(\d{2})`
   - Шаблон замены: `+380 $1 $2 $3 $4`
   - Принцип работы: Регулярное выражение выделяет код оператора и группы цифр номера в отдельные захватывающие группы, которые затем перестраиваются в соответствии с требуемым стандартом.

## Инструкция по эксплуатации
1. Запустите приложение.
2. Введите полный путь к папке, содержащей целевые текстовые файлы.
3. Программа выполнит чтение, модификацию и перезапись файлов.
4. По завершении процесса в консоли отобразится список обработанных объектов.

## Примеры преобразования данных

| Категория | Исходный текст | Обработанный текст |
| :--- | :--- | :--- |
| Орфография | првиет, здраствуйте | привет, здравствуйте |
| Телефон | (012) 345-67-89 | +380 12 345 67 89 |
| Телефон | (050) 111-22-33 | +380 50 111 22 33 |

## Безопасность и валидация
- Реализована проверка существования указанной директории перед началом выполнения операций.
- Использование методов `File.ReadAllText` и `File.WriteAllText` гарантирует полную перезапись содержимого файла после успешной обработки всех паттернов в оперативной памяти.
